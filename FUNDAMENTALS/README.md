## Learning Objectives

The main purpose of studying Python fundamentals is to build a strong foundation for advanced analytical and scientific work. My focus is not only on writing Python code, but also on understanding how to use Python properly for real-world problem solving.

Key objectives include:

- Strengthening core Python syntax and programming logic
- Writing clean, readable, and reusable code
- Understanding functions, loops, conditionals, and data structures
- Practicing debugging and error handling
- Building confidence with notebooks, scripts, and IDEs
- Preparing for statistics, data science, machine learning, and AI workflows

## Essential Python Fundamentals

Important topics covered or required for a strong Python foundation:

- Variables and data types
- Strings, numbers, booleans, and type conversion
- Lists, tuples, sets, and dictionaries
- Conditional statements
- Loops and iteration
- Functions and parameters
- Scope and return values
- File handling
- Error handling with `try` and `except`
- Modules and packages
- Object-oriented programming basics
- Working with external libraries
- Writing and running Python scripts
- Using Jupyter Notebook for experimentation
